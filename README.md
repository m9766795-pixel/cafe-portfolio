# cafe-portfolio

Figma で作成した架空のコーヒーショップのデザインをもとに、  
HTML・CSS（SCSS）・JavaScript で実装した学習用のランディングページです。

## デモ

https://github.com/m9766795-pixel/cafe-portfolio.git

## 使用技術

- HTML
- CSS（SCSS）
- JavaScript
- Figma
- Photoshop
- GitHub / GitHub Pages

## 実装内容

- PC・スマートフォン両方に対応したレスポンシブデザイン
- ハンバーガーメニューの開閉
- スクロールに合わせた表示
- 画像や余白を活かしたレイアウト

## 工夫した点

- スマートフォンでも読みやすくなるよう、文字サイズと余白を調整しました。
- ハンバーガーメニューは、JavaScript で開閉できるように実装しました。
- デザインカンプをもとに、レイアウトや配色を丁寧に再現することを意識しました。

## 苦労した点・学び

- レスポンシブ対応では、画面幅ごとにレイアウトが崩れないよう調整する必要がありました。
- CSS のクラス設計を見直すことで、修正しやすいコードに近づけました。
- 今後は、アクセシビリティや表示速度にも配慮した実装を学びたいです。

## ローカルで確認する方法

このリポジトリをダウンロードまたはクローンした後、`index.html` をブラウザーで開くと確認できます。

## 注意

本サイトは、ポートフォリオ用に作成した架空のデザインです。
